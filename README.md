# Sistem Pencatatan Hasil Panen Digital

**Deskripsi Singkat:**
Program ini adalah aplikasi sederhana berbasis Python yang digunakan untuk menghitung total hasil panen komoditas agroindustri (dalam satuan kilogram) secara otomatis, sekaligus menghitung jumlah diskon potongan yang diberikan.

**Cara Menjalankan Program:**
1. Pastikan Python sudah terinstal di komputermu.
2. Buka terminal atau Command Prompt.
3. Arahkan ke folder tempat file disimpan.
4. Ketik dan jalankan perintah berikut: `python panen.py`
